Deviation = ultra-short-term forecast − theoretical production (positive = forecast too high).
Metered (meter reading) comes from the meter data in the vcom repository (click its legend entry to hide it); it includes grid curtailment, unlike theoretical production. In the All sites view an interval counts only if all five sites have a reading.
Ultra-short-term (UST) forecast: the supplier’s rolling POA forecast (new issue every 15 minutes, 0–4 h ahead), converted to production with the same formula as theoretical production (DC capacity × monthly PR, AC limit). It is a shadow forecast, not a declaration basis. Lead time = how many minutes before the interval starts the forecast was issued. For each interval the line uses the issue with the smallest lead time at or above the chosen value (if that one is missing, the next older issue). Each issue is available about 26 minutes after its issue time and intraday gates close roughly 15 minutes before delivery, so 45 min is the shortest lead time that can still be used for trading (default); 15 and 30 min are only meaningful for after-the-fact evaluation. In hourly view, four 15-min values are summed (all four must exist) and the shown lead time is the oldest of the four.
UST data is only available from the day the collection started; earlier periods stay empty.

Theoretical production is calculated from VCOM POA irradiance (includes the AC limit, excludes grid curtailment); it is not the meter reading. Statistics only use intervals where theoretical production and the forecast are both available.
Dev. % = (Σforecast − Σtheoretical) / Σtheoretical — net bias; over- and under-forecasts cancel out (negative = forecast too low overall).
Abs. error % = Σ|forecast − theoretical| / Σtheoretical — every interval’s error counts in full, so errors do not cancel out.
