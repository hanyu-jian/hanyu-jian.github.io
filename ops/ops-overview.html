Deviation = production forecast − theoretical production (positive = forecast too high).
Metered (meter reading) comes from the meter data in the vcom repository (click its legend entry to hide it); it includes grid curtailment, unlike theoretical production. In the All sites view an interval counts only if all five sites have a reading.
Production forecast: DA is the base forecast. IDA1, IDA2, IDA3 and ID3 are successive revisions of it; where a revision has no value for an interval, the previous version carries forward. The orange line is DA with every revision up to the chosen version applied (default: Latest).

Theoretical production is calculated from VCOM POA irradiance (includes the AC limit, excludes grid curtailment); it is not the meter reading. Statistics only use intervals where theoretical production and the respective forecast are both available.
Dev. % = (Σforecast − Σtheoretical) / Σtheoretical — net bias; over- and under-forecasts cancel out (negative = forecast too low overall).
Abs. error % = Σ|forecast − theoretical| / Σtheoretical — every interval’s error counts in full, so errors do not cancel out.
